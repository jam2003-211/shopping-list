# 買い物リスト通知アプリ

## 目的

iPhoneで使用できる買い物リストWebアプリ（PWA）を作る。

買い忘れを防ぐため、買い物リストを登録し、
指定した時間に未購入の商品が残っている場合は通知する。

## 開発環境

-   Windows
-   Codex
-   iPhone
-   PWA（Progressive Web App）

## 基本機能

### 1. 買い物リスト

-   商品を追加できる
-   商品名を入力して登録する
-   登録した商品を一覧表示する
-   購入した商品にチェックを付けられる
-   商品を削除できる

### 2. データ保存

-   アプリを閉じても買い物リストを保持する
-   最初はlocalStorageを使用する

### 3. 通知

-   通知する日時を設定できる
-   未購入の商品がある場合に通知する
-   iPhoneへのWeb Push通知は後の段階で実装する

### 4. PWA

-   iPhoneのホーム画面に追加できる
-   ホーム画面からアプリのように起動できる
-   アプリアイコンを設定する
-   standalone表示に対応する

## 画面構成

### メイン画面

-   買い物リスト
-   商品名入力欄
-   追加ボタン
-   商品ごとのチェック欄
-   通知日時の設定
-   通知設定ボタン

## デザイン

-   iPhoneで使いやすいデザイン
-   シンプル
-   大きめのボタン
-   片手でも操作しやすい
-   買い物中でも確認しやすい

## 開発方針

まず以下の順番で実装する。

1.  買い物リスト
2.  localStorageによる保存
3.  スマートフォン向けUI
4.  PWA化
5.  通知機能
6.  iPhoneで動作確認
